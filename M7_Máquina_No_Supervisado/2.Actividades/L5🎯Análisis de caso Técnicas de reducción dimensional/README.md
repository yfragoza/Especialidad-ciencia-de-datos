# Actividad - Técnicas de reducción dimensional

## Descripción
Actividad práctica sobre reducción dimensional aplicada a un dataset clínico de alta dimensionalidad. Se utilizan StandardScaler, PCA y t-SNE para reducir variables, visualizar patrones y comparar ambas técnicas.

## Tecnologías usadas
- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Estructura
- `reduccion_dimensional/main.py`
- `doc/informe_tecnico_reduccion_dimensional.md`
