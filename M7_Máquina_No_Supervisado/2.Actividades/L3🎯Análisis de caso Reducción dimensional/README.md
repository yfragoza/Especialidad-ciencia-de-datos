# Actividad - Reducción dimensional

## Descripción
Actividad práctica de reducción dimensional con Python. Se aplican las técnicas PCA y t-SNE sobre un dataset de alta dimensionalidad para comparar resultados y generar visualizaciones 2D.

## Tecnologías usadas
- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Estructura
