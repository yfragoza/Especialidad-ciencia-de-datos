# Actividad - Métricas de desempeño de un algoritmo de regresión

## Descripción
Actividad práctica de regresión lineal con Python y Scikit-Learn para predecir el precio de vehículos usados y evaluar el modelo con métricas de desempeño.

## Tecnologías usadas
- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Estructura
- `metricas_regresion/main.py`
- `doc/informe_metricas_regresion.md`
