# Actividad - Preprocesamiento y escalamiento de datos

## Descripción
Actividad práctica de preprocesamiento de datos con Python y Scikit-Learn. Incluye imputación de valores nulos, codificación de variables categóricas y escalamiento de variables numéricas.

## Tecnologías usadas
- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Estructura
- `preprocesamiento/main.py`
- `doc/informe_preprocesamiento_escalamiento.md`

pip install pandas numpy matplotlib scikit-learn
