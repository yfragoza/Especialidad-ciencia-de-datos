# Proyecto Integrador - Módulo 6: Aprendizaje de Máquina Supervisado

## Descripción
Proyecto de regresión supervisada para predecir el monto promedio de compra de clientes de e-commerce a partir de variables demográficas y de comportamiento digital.

## Tecnologías utilizadas
- Python 3
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Estructura del proyecto
- `ml_supervisado/main.py`: script principal
- `doc/informe_modelo_prediccion_gasto.md`: informe técnico
- `ml_supervisado/graficos/`: visualizaciones exportadas
- `ml_supervisado/resultados/`: métricas, validación y selección de modelo
