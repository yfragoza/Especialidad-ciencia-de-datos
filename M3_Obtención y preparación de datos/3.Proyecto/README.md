# Proyecto Integrador - Preparación de Datos con Python

## Descripción
Proyecto desarrollado con Python, NumPy y Pandas para implementar un flujo completo de preparación de datos, incluyendo generación, exploración, integración de fuentes, limpieza, wrangling, agrupamiento y exportación final.

## Tecnologías usadas
- Python 3
- NumPy
- Pandas
- OpenPyXL

## Estructura del proyecto
- `preparacion_datos/main.py`: script principal
- `doc/informe_proyecto_preparacion_datos.md`: documento resumen
- archivos CSV, Excel, NPY y HTML generados automáticamente durante la ejecución

## Funcionalidades
- Generación de datos ficticios con NumPy
- Exploración con Pandas
- Lectura desde CSV, Excel y tabla web
- Integración de fuentes con merge y concat
- Gestión de valores nulos
- Detección y tratamiento de outliers
- Data Wrangling
- Groupby, pivot y melt
- Exportación final a CSV y Excel
