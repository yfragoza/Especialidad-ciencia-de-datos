# Proyecto Pandas - Obtención de Datos desde Archivos

## Descripción
Proyecto desarrollado con Pandas para cargar datos desde archivos CSV, Excel y tablas web, realizar limpieza de datos y exportar la información procesada.

## ⚙️ Tecnologías usadas
- Python 3
- Pandas
- NumPy
- OpenPyXL (manejo de archivos Excel)
- lxml / html5lib (extracción de tablas web)

## Funcionalidades
- Carga de datos desde CSV
- Carga de datos desde Excel
- Extracción de tabla web
- Detección y tratamiento de valores nulos
- Eliminación de duplicados
- Conversión de tipos de datos
- Selección y renombrado de columnas
- Ordenamiento de datos
- Exportación a CSV y Excel

## Archivos generados
Los archivos CSV y Excel son generados automáticamente al ejecutar el script y se incluyen como evidencia del procesamiento de datos.

## Ejecución

```bash
python main.py
