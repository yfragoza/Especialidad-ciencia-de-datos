# 📊 Proyecto NumPy - Análisis de Datos

## 📌 Descripción
Este proyecto utiliza la librería NumPy para analizar datos financieros simulados.

## ⚙️ Tecnologías usadas
- Python 3
- Numpy

## ⚙️ Funcionalidades
- Creación de matrices
- Cálculos estadísticos
- Variación porcentual
- Transformaciones matemáticas
- Filtrado de datos
- Normalización

## ▶️ Ejecución

```bash
python main.py
