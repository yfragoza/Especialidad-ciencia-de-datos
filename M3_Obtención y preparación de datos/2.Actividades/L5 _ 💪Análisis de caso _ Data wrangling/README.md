# Proyecto - Data Wrangling con Pandas

## Descripción
Proyecto desarrollado con Pandas para aplicar técnicas de Data Wrangling sobre un dataset CSV, incluyendo exploración, limpieza, transformación, agrupación y exportación.

## ⚙️ Tecnologías usadas
- Python 3
- Pandas
- NumPy
- OpenPyXL

## Funcionalidades
- Carga de datos desde CSV
- Exploración con head, info y describe
- Detección de nulos y duplicados
- Imputación de valores faltantes
- Eliminación de duplicados
- Conversión de variables categóricas en numéricas
- Groupby y agregación
- Filtrado de subconjuntos
- Renombrado y reorganización de columnas
- Exportación a CSV y Excel

## Ejecución

```bash
python main.py
