# Proyecto Integrador - EDA para decisiones comerciales

## Descripción
Proyecto de análisis exploratorio de datos aplicado a un caso de negocio de e-commerce. Incluye estadística descriptiva, detección de outliers, correlación, regresión lineal y visualización con Seaborn y Matplotlib.

## Tecnologías usadas
- Python 3
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Statsmodels
- Scikit-learn

## Estructura
- `analisis_exploratorio/main.py`
- `doc/informe_eda_comercioya.md`
- `analisis_exploratorio/graficos/`
- `analisis_exploratorio/resultados/`
