# 📇 Sistema de Gestión de Contactos

## 🧠 Descripción

Este proyecto consiste en el desarrollo de un sistema de gestión de contactos en Python, que permite registrar, editar, eliminar y buscar contactos de forma sencilla a través de una interfaz por consola.

El sistema fue desarrollado aplicando conceptos fundamentales de programación como estructuras de datos, programación orientada a objetos y pruebas unitarias.
---

## 🎯 Objetivo

Desarrollar una aplicación funcional que permita gestionar contactos utilizando Python, aplicando buenas prácticas de programación, organización de código y validación mediante pruebas.
---

## Funcionalidades
- Agregar contacto
- Listar contactos
- Buscar por nombre
- Buscar por teléfono
- Editar contacto
- Eliminar contacto
---

## ⚙️ Tecnologías usadas
- Python 3
- Programación orientada a objetos (POO)
- Listas y diccionarios
- unittest (pruebas unitarias)
