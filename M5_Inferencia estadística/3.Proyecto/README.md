# Proyecto Integrador - Módulo 5: Inferencia Estadística

## Descripción
Proyecto de análisis estadístico sobre hábitos saludables en jóvenes universitarios. Incluye aplicación del método científico, simulación de datos, probabilidad, distribuciones, Teorema del Límite Central, intervalos de confianza y pruebas de hipótesis.

## Tecnologías utilizadas
- Python 3
- NumPy
- Pandas
- Matplotlib
- SciPy

## Estructura del proyecto
- `inferencia_estadistica/main.py`: script principal
- `doc/informe_final_habitos_saludables.md`: informe final
- `inferencia_estadistica/graficos/`: gráficos exportados
- `inferencia_estadistica/resultados/`: resultados y archivos de análisis
